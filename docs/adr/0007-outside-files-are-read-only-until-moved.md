# Outside Files are read-only until moved

MacJot is listed in Finder's Open With for Markdown files, but it only edits Notes: the top-level `.md` files of the Notes Folder. Any other Markdown file it's handed is an Outside File, shown read-only with a **Move to Notes Folder** button; once moved, it's an ordinary Note. We first showed an alert and opened nothing (ticket 30), which was frustrating in use. Editing in place was rejected because everything else assumes one folder: the Note List, Search, renaming after the Title (ADR 0003) and trashing an emptied Note would each need an exception for files elsewhere, some of which MacJot shouldn't rename or trash at all. Copying into the Notes Folder was rejected because two versions drift apart; moving breaks other apps' links to the file instead, which the user accepts by clicking the button. Moving out of Desktop, Downloads or other protected folders may bring up macOS's one-time folder prompt; no Full Disk Access is needed.
