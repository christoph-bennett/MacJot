# Clips carry frontmatter

A Note created from a selection in another app (a Clip) is written with YAML frontmatter holding `created` (local time with offset), `source` (the app) and `page` (the front window's title with the app's name and browser profile removed, left out for Terminal and iTerm); values that are unknown are left out, and a Clip from the clipboard or the Service has neither `source` nor `page`. Ordinary Notes still get none, so this reverses spec 0001 story 43 ("write no frontmatter") for Clips only; existing frontmatter is still preserved verbatim and skipped when deriving the Title. The key names match the app Jot, which Christoph tested beside MacJot, so its Clips stay readable in both; we left out its `id`, `done`, `pin`, `archived`, `section`, `tags` and `images`, because MacJot has no such features. The Frontmatter Section shows the block collapsed by default in every Note that has one, so the YAML doesn't get in the way of reading.
