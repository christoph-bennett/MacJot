# Clips are read through ⌘C and the pasteboard

The Clip Hotkey presses ⌘C in the frontmost app, reads the pasteboard and restores the previous clipboard, which needs the Accessibility permission (decided 2026-11-15). We rejected reading the selection through the Accessibility API (the same permission, but text only, and it fails in browsers and Electron apps) and a Services menu entry (no permission, but its shortcut is assigned in System Settings, outside MacJot's Shortcuts pane); a Service stays an option for later if the permission proves a problem. The pasteboard route also hands MacJot whatever else the app copies, which later work on images needs. The costs: clipboard managers see the ⌘C and the restore, and macOS ties the Accessibility grant to the app's code signature, so `scripts/bundle.sh` has to sign with a stable identity (the Apple Development certificate) instead of ad-hoc, or the grant resets at every install.
