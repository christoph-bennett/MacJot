# KeyboardShortcuts for the hotkeys

The Capture and Search Hotkeys are recorded, stored and registered with sindresorhus/KeyboardShortcuts (MIT), Jot's first third-party dependency; it replaces our own `GlobalHotkey`. Recording a global hotkey well takes more than a key-down handler: a native-looking recorder field, keys labelled for the current keyboard layout, global hotkeys paused while recording (or ⌃⌥N would open the Capture Panel mid-recording), warnings for combinations macOS already uses, and fixes for AppKit quirks that change with each macOS release. The package does all of that and is maintained. We rejected writing our own recorder modelled on it (the same features, but the macOS-version quirks would be ours to find) and keeping Settings read-only. Where a dependency was only a thin wrapper, we wrote our own code instead (the Settings panes, launch at login). The costs: `scripts/bundle.sh` must copy the package's resource bundle into `Jot.app`, or the recorder crashes when it shows its texts; and like any approach, it can't detect a combination another app has registered, only ones macOS itself uses.
